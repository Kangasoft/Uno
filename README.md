This is a recreation of the Classic UNO! game by Mattel, using the original game rules and 108 UNO! cards.

This was mainly a challenge to write it in WinForms 2.0, with a lot of custom painting; and, not resorting to short-cuts by using WinForm's PictureBox controls (which a lot of people do "just to get it done", and I don't like).

It is written in C# .NET 4.8.1 using Visual Studio 2017 Community Edition.
